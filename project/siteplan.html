Website Planning Document

Luis Quezada Engineering Portfolio

Site Purpose

The name clearly identifies the website as my personal engineering portfolio. It reflects my professional identity and communicates that visitors will find information about my education, engineering experience, projects, and technical skills.

Optional domain availability: luisquezada.dev or luisquezadaengineering.com

Scenarios

  • What engineering projects has Luis worked on during his professional career?
  • What software and technical skills does Luis have?
  • How can I contact Luis for an engineering opportunity?

Color Schema

Color Hex Use
Navy Blue #1F3B5C Headers, Navigation, Buttons
Light Gray #E8ECEF Background
White #FFFFFF Cards
Accent Blue #3A86FF Links, Hover Effects

Typography

Headings will use the Montserrat font to create a clean and modern appearance. Body text will use Roboto for readability across all devices.
